# DJ Remax — دي جي ريمكس

تطبيق مستقل لإدارة حجوزات خدمة الدي جي. ما يعتمد على أي ملف خارج هذا المجلد.

- **الحجوزات:** تقويم شهري. اضغط على اليوم لإضافة حجز، واضغط على الحجز لعرض معلوماته أو نسخ رسالة الحجز مع سياسة الإلغاء.
- **المصاريف:** تسجيل المصاريف وربطها بحجز معيّن إذا تبي.
- **المالية:** خصم المصاريف من الحجوزات، وعرض صافي كل حجز وكل شهر والسنة.
- **الإعدادات:** اسم الخدمة ورقم التواصل والموقع وسياسة الإلغاء، والنسخ الاحتياطي.

## التشغيل
افتح `index.html` في المتصفح، أو شغّل خادم محلي من داخل المجلد:

```
python3 -m http.server 8000
```

البيانات تنحفظ في متصفح الجهاز (localStorage) بمفاتيح خاصة بالتطبيق (`djremax_*`).
